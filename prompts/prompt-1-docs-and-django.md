## بخش الف: یکپارچه‌کردن اسناد
۱. این فایل‌ها را کامل بخوان: `AGENTS.md`، `product.md`، `design.md` و `openspec/config.yaml`.
۲. از روی ایده‌ی من `product.md` را پر کن: نام محصول، یک جمله‌ی معرفی، کاربران، مشکل و هدف، حداکثر سه قابلیت برنامه‌ریزی‌شده (اولی همان است که در کارگاه می‌سازیم)، اطلاعاتی که نگه داشته می‌شود، خارج از محدوده، و لحن. چیزی را که نگفته‌ام از خودت نساز؛ آن را در بخش `Open Questions` بنویس.
۳. اگر چیز مهمی مبهم است، قبل از نوشتن حداکثر سه سؤال محصولی کوتاه بپرس، هر کدام با چند گزینه که یکی «پیشنهادی» باشد.
۴. در `openspec/config.yaml` به‌جای `[PROJECT_NAME]` و `[ONE_SENTENCE]` نام و جمله‌ی معرفی محصول را بگذار. در `design.md` فقط `Product name` را پر کن؛ رنگ، فونت و لوگو برای مرحله‌ی سیستم طراحی خالی بماند.
۵. هر چهار سند را با هم یکدست کن: نام محصول، محدوده، اصطلاحات و قانون‌ها همه‌جا یکی باشند و هیچ‌کدام با `AGENTS.md` تناقض نداشته باشد.
۶. اگر ابزار کدنویسی تو به‌جای `AGENTS.md` فایل دیگری می‌خواند (مثلاً Claude Code فایل `CLAUDE.md` را)، آن فایل را بساز و فقط یک خط `@AGENTS.md` در آن بگذار.

## بخش ب: ساختن پایه‌ی جنگو و بوت‌استرپ
طبق بخش‌های `Project Structure`، `Django Settings` و `Tooling and Git` در `AGENTS.md`:
۱. **پایتون با uv:** اگر `pyproject.toml` نیست، `uv init` بزن و فقط `django` را با `uv add django` اضافه کن. فایل‌های نمونه‌ی اضافه (مثل `main.py`) را پاک کن.
۲. **پروژه‌ی جنگو:** `uv run django-admin startproject config .` و اپ `core` (ثبت در `INSTALLED_APPS`). زبان `fa`، منطقه‌ی زمانی `Asia/Tehran`، SQLite، پوشه‌های ریشه‌ی `templates/` و `static/`. `config/urls.py` فقط `core.urls` و admin را include کند. بعد `migrate` بزن.
۳. **پوشه‌ها:** کل ساختار `static/` را بساز: `css/`، `css/vendor/`، `js/`، `js/vendor/`، و دو پوشه‌ی خالی `fonts/` و `brand/` (هر کدام با یک `.gitkeep`) که بعداً فونت و لوگو را در آن‌ها می‌گذارم.
۴. **بوت‌استرپ محلی:** آخرین نسخه‌ی پایدار Bootstrap 5 را یک بار دانلود کن و `bootstrap.rtl.min.css` را در `static/css/vendor/` و `bootstrap.bundle.min.js` را در `static/js/vendor/` بگذار. هیچ لینک CDN نباشد.
۵. **قالب پایه:** `templates/base.html` با `<html lang="fa" dir="rtl">`، بوت‌استرپ RTL، `static/css/theme.css` (فعلاً فقط فونت `system-ui` و چند متغیر خنثی)، نوار بالا که در موبایل جمع شود، محل نمایش پیام‌ها و فوتر. پوشه‌ی `templates/components/` را بساز.
۶. **صفحه‌ی اصلی:** `/` یک صفحه‌ی ساده‌ی خوش‌آمد با نام محصول. هیچ قابلیت محصولی نساز.
۷. **Git:** اگر راه‌اندازی نشده، `git init` (هویت فقط برای همین پروژه، طبق `AGENTS.md`) و یک `.gitignore` مناسب جنگو (`db.sqlite3`، `.venv/`، `__pycache__/`، `.env`).
۸. **بررسی:** یک تست ساده برای صفحه‌ی `/` در `core/tests.py` بنویس، بعد `uv run python manage.py check`، `uv run python manage.py makemigrations --check --dry-run` و `uv run python manage.py test` را اجرا کن. سرور را خودت روشن نگه ندار.
۹. **مستندات و کامیت:** اگر ساختار واقعی با `AGENTS.md` فرق دارد، آن را به‌روز کن؛ در جدول `product.md` این مرحله را `built` بزن؛ با پیام `chore: align docs and set up django bootstrap base` کامیت کن.
